# 🧪 DOSOFT 1.3.9 — BÊTA

**Correctif Affichage Dofus et récupération des interfaces**

- Le fichier global Dofus vide ne bloque plus l'enregistrement avec l'erreur
  « après 5 tentatives ».
- Les réglages globaux du profil précédent sont conservés lorsque ce fichier
  est vide.
- L'application du profil retire la demande de réinitialisation des positions.
- Sauvegardes de sécurité améliorées, conservation séparée des fichiers abîmés
  et retour aux originaux en cas d'échec d'écriture.
- Journal de diagnostic et nouveaux messages traduits dans les cinq langues.
- Correctifs Stream Deck, barre de personnages et captures Unity inclus.

**Pour retrouver votre interface sauvegardée :**
Fermez tous les clients Dofus, puis ouvrez **Paramètres → Affichage Dofus →
Appliquer aux comptes**. N'écrasez pas votre ancien profil en réenregistrant une
interface déjà réinitialisée.

**Installation :** exécutez `Dosoft_BETA_Setup_v1.3.9.exe` par-dessus votre
installation actuelle. Vos profils locaux sont conservés.

**C'est une bêta :** signalez les problèmes avec la version 1.3.9, le moteur
utilisé, les étapes pour reproduire et les journaux utiles. Masquez les données
personnelles avant de les partager.

**Canal officiel :** <https://dosoft.fr>
Ne téléchargez pas de version envoyée par message privé.
